# Уведомления в Telegram

Когда директор ставит счёту статус **«В оплату»**, бухгалтеру приходит
сообщение в Telegram со всей нужной информацией и ссылкой на счёт.
Настройка занимает 10 минут, всё бесплатно.

Пример сообщения:

> **📝 Счёт отправлен В ОПЛАТУ**
>
> Счёт № 607
> Проект: **Сузун**
> Сумма: **40 343,00 ₽** (НДС 22%)
> Поставщик: ЦЕНТР СТРОИТЕЛЬНЫХ МАТЕРИАЛОВ И ТЕХНОЛОГИЙ
> Что: ЦМИД-3 1 тонна
> Оплатить до: **2026-09-10**
>
> [Открыть счёт](#)

---

## Шаг 1. Создать бота

1. В Telegram найдите **@BotFather** и напишите ему `/newbot`.
2. Придумайте имя (например «Счета компании») и логин, оканчивающийся
   на `bot` (например `scheta_nasha_bot`).
3. BotFather пришлёт **токен** вида
   `8123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохраните его.

## Шаг 2. Создать группу и добавить бота

Рекомендую слать не в личку, а в **группу** — тогда уведомления видят и
бухгалтер, и директор, и снабженец, и переписка остаётся в одном месте.

1. Создайте в Telegram группу, например «Счета на оплату».
2. Добавьте туда бухгалтера и всех, кому нужны уведомления.
3. Добавьте в группу вашего бота (по логину из шага 1).

## Шаг 3. Узнать id чата

1. Напишите в группе любое сообщение (например «привет»).
2. Откройте в браузере ссылку, подставив свой токен:

   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```

3. В ответе найдите `"chat":{"id":-1001234567890`. Число вместе со
   знаком минус — это **id чата**. Сохраните его.

> Если ответ пустой — напишите в группе ещё раз и обновите страницу.

## Шаг 4. Вписать настройки на сервере

Откройте `server_start.bat` в Блокноте и заполните строки:

```
set TELEGRAM_BOT_TOKEN=8123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
set TELEGRAM_CHAT_ID=-1001234567890
set NOTIFY_STATUSES=to_pay,paid
set APP_BASE_URL=https://scheta.вашакомпания.ru
```

Перезапустите приложение:

```
schtasks /End /TN "Scheta i KP"
schtasks /Run /TN "Scheta i KP"
```

Теперь откройте любой счёт и нажмите «В оплату» — в группе появится
сообщение.

## Настройки

| Переменная | Что делает |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | Куда слать (id группы или личного чата) |
| `NOTIFY_STATUSES` | При каких статусах слать, через запятую |
| `APP_BASE_URL` | Адрес приложения — чтобы ссылка в сообщении работала |

Возможные значения `NOTIFY_STATUSES`:

- `to_pay` — счёт отправлен в оплату (нужен бухгалтеру);
- `paid` — счёт оплачен (нужен снабженцу — можно ехать забирать);
- `received` — товар забрали;
- `new` — счёт вернули во «Входящие».

По умолчанию `to_pay,paid`. Оставьте `TELEGRAM_BOT_TOKEN` пустым, чтобы
выключить уведомления совсем.

## Важно про ссылку в сообщении

Ссылка ведёт на счёт, и открыть его можно только после входа по паролю.
Чтобы ссылка работала с телефона откуда угодно, в `APP_BASE_URL` должен
стоять внешний адрес (через Cloudflare Tunnel, см.
[deploy-windows.md](deploy-windows.md)). Если приложение работает только
в офисной сети, укажите `http://IP-сервера:8000` — ссылка будет
открываться лишь из офиса.

## Если сообщения не приходят

- Проверьте, что бот **добавлен в группу** — в личку незнакомым бот писать не может.
- Проверьте id чата: у групп он **отрицательный**, со знаком минус.
- После правки `server_start.bat` приложение нужно **перезапустить**.
- Посмотрите чёрное окно сервера: при ошибке там будет строка
  «Не удалось отправить уведомление в Telegram» с причиной.

## Почему Telegram, а не WhatsApp или Max

- **Telegram** — боты бесплатны, настройка 10 минут, ограничений нет.
- **WhatsApp** — своих ботов нет; нужен платный WhatsApp Business API
  через партнёра (обычно от ~2000 ₽/мес плюс плата за сообщения) и
  проверка компании. Технически подключаемо, но дорого и долго.
- **Max** — API для ботов есть, но пока сырой и меняется; сделать можно,
  если у вас вся команда уже сидит в Max.

Если понадобится WhatsApp или Max — скажите, добавим отправку туда же
рядом с Telegram, менять остальное не придётся.
