# Установка на офисный сервер Windows + доступ из интернета

Инструкция для варианта, когда приложение работает **на своём сервере в
офисе**, а сотрудники заходят с телефонов **из любого места** — через
Cloudflare Tunnel, бесплатно и без аренды сервера.

Что получится в итоге:

- приложение работает круглосуточно и запускается само после перезагрузки;
- сотрудники заходят по адресу вида `https://scheta.вашакомпания.ru`;
- порты на роутере **не открываются**, офисная сеть наружу не выставляется;
- HTTPS-сертификат выдаётся и продлевается автоматически;
- каждую ночь делается резервная копия.

Разовые расходы: только домен, примерно **200–800 ₽/год**. Сам туннель бесплатный.

---

## Часть 1. Запустить приложение на сервере

### Шаг 1. Установить Python

На сервере скачайте Python с https://www.python.org/downloads/ и установите.
В установщике обязательно поставьте галочку **«Add Python to PATH»**.

### Шаг 2. Скопировать проект

Положите папку с проектом в постоянное место, например `C:\Scheta`.
Не кладите её на рабочий стол или во «Временные файлы».

### Шаг 3. Задать пароль

Откройте `server_start.bat` в Блокноте и впишите пароль в строку:

```
set APP_PASSWORD=придумайте-пароль
```

> Это обязательно. Приложение будет доступно из интернета — без пароля
> войти сможет любой, кто узнает адрес.

### Шаг 4. Проверить запуск

Двойной клик по `server_start.bat`. Должно появиться сообщение
«Приложение запущено на порту 8000». Откройте на самом сервере
http://localhost:8000 — должна открыться страница входа.

Если всё работает, закройте окно (Ctrl+C) и переходите дальше.

### Шаг 5. Включить автозапуск

Нажмите на `server_install_autostart.bat` **правой кнопкой** →
**«Запуск от имени администратора»**.

Скрипт создаст задачу Windows, которая запускает приложение при
включении сервера. Теперь чёрное окно держать открытым не нужно.

Полезные команды (в командной строке от администратора):

```
schtasks /Run    /TN "Scheta i KP"      :: запустить сейчас
schtasks /End    /TN "Scheta i KP"      :: остановить
schtasks /Delete /TN "Scheta i KP" /F   :: убрать автозапуск
```

Запустите приложение прямо сейчас первой командой и проверьте
http://localhost:8000 ещё раз.

## Часть 2. Открыть доступ из интернета (Cloudflare Tunnel)

Туннель работает так: на сервере запускается программа `cloudflared`,
которая сама **изнутри** подключается к Cloudflare. Входящие порты
открывать не нужно — снаружи в вашу сеть никто не «стучится».

### Шаг 6. Завести домен

Купите домен у любого регистратора (reg.ru, timeweb, nic.ru) —
например `вашакомпания.ru`. Приложение будет доступно на
поддомене, скажем `scheta.вашакомпания.ru`.

### Шаг 7. Подключить домен к Cloudflare

1. Зарегистрируйтесь бесплатно на https://dash.cloudflare.com
2. Нажмите **Add a domain**, введите ваш домен, выберите план **Free**.
3. Cloudflare покажет два адреса вида `xxx.ns.cloudflare.com`.
4. Зайдите в личный кабинет регистратора, где купили домен, и замените
   там NS-серверы (DNS-серверы) на выданные Cloudflare.
5. Подождите — обычно 15 минут, иногда до суток. Домен в Cloudflare
   станет **Active**.

### Шаг 8. Создать туннель

1. В Cloudflare слева выберите **Zero Trust** → **Networks** → **Tunnels**.
2. **Create a tunnel** → тип **Cloudflared** → назовите, например `office`.
3. На шаге установки выберите **Windows** и скачайте `cloudflared`.
4. Cloudflare покажет готовую команду вида
   `cloudflared.exe service install ВАШ_ДЛИННЫЙ_ТОКЕН`.
   Скопируйте её.
5. На сервере откройте командную строку **от имени администратора**,
   перейдите в папку со скачанным файлом и выполните эту команду.
   Она установит `cloudflared` как службу Windows — он тоже будет
   запускаться сам.

### Шаг 9. Направить домен на приложение

В том же окне Cloudflare, на вкладке **Public Hostname**, нажмите
**Add a public hostname** и заполните:

| Поле | Значение |
|---|---|
| Subdomain | `scheta` |
| Domain | ваш домен |
| Type | `HTTP` |
| URL | `localhost:8000` |

Сохраните. Через минуту откройте с телефона (можно по мобильному
интернету, не через офисный Wi-Fi):

```
https://scheta.вашакомпания.ru
```

Должна открыться страница входа. Готово — приложение доступно отовсюду.

### Шаг 10. Добавить на телефоны

На каждом телефоне откройте адрес, войдите по паролю и добавьте на
главный экран: **Android** — меню Chrome → «Добавить на главный экран»;
**iPhone** — кнопка «Поделиться» → «На экран „Домой“».

## Часть 3. Резервные копии

Копия — это база со всеми счетами и все прикреплённые файлы в одном
zip-архиве. Скрипт корректно копирует базу даже во время работы.

### Проверить вручную

Двойной клик по `backup.bat`. В папке `backups` появится
`backup-ГГГГ-ММ-ДД_ЧЧ-ММ.zip`.

Копии старше 30 дней удаляются автоматически.

> Лучше складывать копии не на тот же диск. Откройте `backup.bat`
> в Блокноте и укажите другой диск или сетевую папку:
> `set BACKUP_DIR=D:\Backups\Scheta`

### Настроить ежедневную копию

Командная строка **от имени администратора**:

```
schtasks /Create /TN "Scheta backup" /TR "C:\Scheta\backup.bat" /SC DAILY /ST 22:00 /RU SYSTEM /F
```

Замените `C:\Scheta` на свой путь. Копия будет делаться каждый день в 22:00.

### Как восстановить из копии

1. Остановите приложение: `schtasks /End /TN "Scheta i KP"`
2. Распакуйте архив.
3. Положите `invoices.db` и папку `uploads` в папку `data` проекта,
   заменив существующие.
4. Запустите: `schtasks /Run /TN "Scheta i KP"`

---

## Обновление приложения

1. Остановите: `schtasks /End /TN "Scheta i KP"`
2. Сделайте копию: `backup.bat`
3. Скачайте новую версию и распакуйте поверх папки проекта,
   **не трогая папку `data`** — в ней все ваши счета и файлы.
4. Запустите: `schtasks /Run /TN "Scheta i KP"`

## Если что-то не работает

**Не открывается на самом сервере (localhost:8000)** — приложение не
запущено. Запустите `server_start.bat` вручную и посмотрите текст ошибки
в чёрном окне.

**Открывается на сервере, но не по домену** — проблема в туннеле.
Проверьте, что служба работает: `sc query cloudflared`. В Cloudflare в
разделе Tunnels туннель должен быть **HEALTHY**.

**Просит пароль, но не пускает** — пароль задаётся в `server_start.bat`.
После его изменения приложение нужно перезапустить
(`schtasks /End` затем `schtasks /Run`).

**Коллеги в офисе тоже могут заходить напрямую**, минуя интернет, по
адресу `http://IP-сервера:8000` — это быстрее. Узнать IP: `python find_ip.py`.
