# Счета и КП — учёт по проектам + платёжный календарь

Простое веб-приложение для компании: учёт входящих счетов и коммерческих
предложений по проектам, с удобным доступом с телефона. Раздел «Деньги»
прогнозирует остаток на счетах на 12 недель вперёд и показывает кассовые
разрывы заранее.

## Раздел «Деньги» (платёжный календарь)

Принцип: приложение **не дублирует бухгалтерию** — раз в день вводится
фактический остаток по счетам из банка, а прогноз считается как
остаток + ожидаемые поступления − планируемые платежи.

- **Календарь** — остаток по дням на 12 недель, кассовые разрывы подсвечены;
  счета без срока оплаты выводятся отдельным списком.
- **Поступления** — план авансов, КС и допработ по каждому проекту со
  статусами План → Подписан → Оплачен. Дата прихода денег считается сама:
  конец месяца подписания + реальная задержка оплаты заказчика; % генподряда
  и гарантийное удержание вычитаются автоматически, возврат удержания
  появляется в прогнозе через заданное число месяцев.
- **Проекты** — финансовые параметры контракта (заказчик, % генподряда,
  % удержания, задержка оплаты, цена контракта) и бюджет из 15–30
  укрупнённых групп. У каждой группы три значения: по смете (неизменно),
  текущая оценка и факт (оплаченные счета). Показывается плановая маржа
  (цена контракта − себестоимость).
- **Загрузка сметы** — двумя способами:
  1. **Через API** (нужен ключ) — файл Excel/CSV или текст, Claude сам
     разбивает смету на группы.
  2. **Без ключа, через claude.ai по подписке** — разбираете смету в
     claude.ai (Проект + файл правил `docs/smeta-rules.md`), вставляете
     готовую разбивку «Название | Категория | Сумма» в приложение; оно
     создаёт группы обычным кодом, бесплатно.

  В обоих случаях результат показывается на экране проверки: вы правите
  группы, вводите итоговую цену контракта, и суммы приводятся к ней
  коэффициентом (смета часто в старых ценах). Категория «Штраф» и счета
  «вне сметы» — для расходов, которых нет в контракте.
- **Постоянные** — зарплата, налоги, аренда, офис: ежемесячные платежи,
  «скелет» календаря.
- У счёта появились поля «Оплатить до», «Критичный» и привязка к группе
  бюджета — неоплаченные счета со сроком попадают в календарь.

## Возможности

- **Проекты** — каждый счёт/КП привязан к проекту, новый проект создаётся прямо из формы.
- **Тип документа** — метка «Счёт» или «КП».
- **Сумма и НДС** — сумма с НДС и ставка (22 %, 20 %, 10 %, 7 %, 5 %, 0 %, без НДС); сумма НДС считается автоматически.
- **Статусы** — Входящий → Оплачен → Забрали, с датой каждой отметки. Статус меняется одной кнопкой.
- **Поставщик** — название, контакты (телефон, менеджер), поле «Откуда и как забирать» (адрес склада, режим работы, пропуск).
- **Файлы** — к записи можно приложить фото счёта с камеры телефона или PDF (а также Excel/Word).
- **Общая таблица** — все счета и КП с фильтрами по проекту, типу (счёт/КП) и статусу (входящие / оплачены / забрали), поиском и итогами (сумма, сумма НДС).
- **Выгрузка в Excel** — кнопка «Excel (CSV)» выгружает текущую выборку.
- **Телефон** — интерфейс адаптирован под мобильный; на Android/iPhone можно добавить на главный экран («Добавить на экран Домой») — будет открываться как приложение.

## Запуск в офисе для теста (вариант Б)

Приложение работает на одном офисном компьютере, который всегда включён,
а телефоны и другие компьютеры заходят к нему по общему Wi-Fi.

1. **Установите Python** на этот компьютер с https://www.python.org/downloads/
   (в установщике для Windows поставьте галочку **«Add Python to PATH»**).
2. Скопируйте на компьютер папку с проектом.
3. Запустите:
   - **Windows** — двойной клик по `start_windows.bat`;
   - **Mac** — двойной клик по `start_mac.command`.
4. В открывшемся чёрном окне будут показаны два адреса:
   - `http://localhost:8000` — открыть на этом же компьютере;
   - `http://<IP>:8000` — вводить на телефоне (телефон должен быть в **том же Wi-Fi**).
5. При первом запуске Windows может спросить про доступ к сети — нажмите **«Разрешить»**.

Окно закрывать нельзя — пока оно открыто, приложение работает. Чтобы задать
общий пароль для входа, откройте скрипт в «Блокноте» и впишите его в строку
`APP_PASSWORD` (см. комментарий внутри файла).

> Это режим для пробы. Он работает только внутри офисной сети. Когда решите
> пользоваться постоянно и заходить из любого места — переходите на вариант А
> (см. «Запуск для компании» ниже).

## Быстрый запуск вручную (локально)

```bash
pip install -r requirements.txt
python app.py
# открыть http://localhost:8000
```

## Запуск для компании (Docker, рекомендуется)

На любом сервере/VPS с Docker:

```bash
APP_PASSWORD=ваш_общий_пароль docker compose up -d --build
```

Приложение будет доступно на порту 8000. Все данные (база и файлы)
хранятся в папке `./data` — её достаточно бэкапить.

Чтобы заходить с телефонов через интернет, поставьте перед приложением
HTTPS-прокси (например, [Caddy](https://caddyserver.com/) — он получает
сертификат автоматически):

```
ваш-домен.ru {
    reverse_proxy localhost:8000
}
```

## Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `APP_PASSWORD` | Общий пароль для входа; пусто — без пароля | пусто |
| `DATA_DIR` | Папка с базой и файлами | `./data` |
| `PORT` | Порт при запуске `python app.py` | `8000` |
| `ANTHROPIC_API_KEY` | Ключ для ИИ-разбора сметы; пусто — функция выключена | пусто |
| `ANTHROPIC_MODEL` | Модель ИИ; для экономии — `claude-haiku-4-5` | `claude-opus-4-8` |

### Как включить ИИ-разбор сметы

Получите ключ на https://console.anthropic.com и задайте его перед запуском.
В `start_windows.bat` добавьте строку рядом с `set APP_PASSWORD=`:

```
set ANTHROPIC_API_KEY=sk-ant-ваш-ключ
```

Без ключа приложение работает как обычно — только кнопка разбора сметы
отключена, а группы бюджета вносятся вручную. Разбор одной сметы стоит
ориентировочно 50–150 ₽; за месяц при обычном объёме — единицы долларов.
Для минимизации расходов поставьте `set ANTHROPIC_MODEL=claude-haiku-4-5`.
